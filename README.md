# -Modulo-de-Gerenciamento-de-Pouso-e-Estabilizacao-de-Base-MGPEB-

Esse programa tem o objetivo de realizar a missão de pousar módulos em Marte, sendo adotado váriaveis e critérios diferentes para o pouso de cada um deles.


1. Para iniciar o programa clique no botão de "play", ou de "executar", conforme o seu programa de visualização.
2. Após iniciar a execução, siga com as etapas de preenchimento dos dados solicitados.
3. Com os dados das váriavés inseridos, será pedido também a altura e velocidade dos módulos.
4. Dito isto, será iniciado a tentativa de pouso para cada módulo (cnforme a sua criticidade e a criticidade da energia da base).
5. Nesta etapa será definido as condições para aterrissagem, caso todas estejam ok, pouso liberado, caso não será abortado.
6. Conforme definido no início, as variavéis serão utilizadas para informar se os módulos ficaram "em espera" (condições boas) ou "em alerta" (alguma condição que afeta o módulo, por isso deve pousar logo).
7. Caso algum fique em alguma condição anterior, será feita nova tentativa de pouso.
8. Ao fim será gerado um relatório com todos os módulos pousados ou não e na ordem que aconteceu. Será dado também informações como tempo para pouso e energia da base final.
